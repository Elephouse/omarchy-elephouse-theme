# Elephouse

A dark Omarchy theme drawn from [Elephouse](https://elephouse.de): warm black paper, a dot-grid notebook, cream ink, and a coral accent.

```sh
omarchy theme install https://github.com/Elephouse/omarchy-elephouse-theme.git
omarchy hook install theme-set ~/.config/omarchy/themes/elephouse/hooks/elephouse-brand
bash ~/.config/omarchy/hooks/theme-set.d/elephouse-brand elephouse
```

The hook puts the elephant on About, the screensaver, fastfetch, and the menu button. Later theme changes apply it on their own.
